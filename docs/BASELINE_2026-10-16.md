# PermitPulse frozen MVP baseline — 2026-10-16

This snapshot freezes the current working implementation for backup and further
minor fixes. Freezing does not imply regulatory approval, compliance, operational
authorization, or that every provider always returns usable data.

## Included implementation

- Single-request Fresh Analyze with authoritative candidate completeness and
  fail-closed incomplete extraction.
- Immutable persisted-analysis restoration, source-page reconciliation and
  source verification.
- Deterministic environmental normalization and explicit Fetch only.
- F04 Human Review, review overlays and bulk approval.
- F09 deterministic Decision & Work Windows using reviewed rules and stored
  evidence; STOP > UNKNOWN > WORK.
- Explicit reference recency policies: Hs 90 minutes, turbidity 72 hours,
  sea-surface modelled dissolved oxygen 24 hours. These are MVP policies, not
  provider-declared continuous validity.
- Variable-scoped depth handling, source-backed zero-depth model levels,
  conservative oxygen depth tolerance, strict units and FNU/NTU separation.
- Informational VMDR wave direction and U/V-derived current direction remain
  non-gating. Current direction is TOWARDS clockwise from north.
- Finder control/session wiring and interval-specific human-readable STOP labels.

## Backup boundary

Source, configuration without credentials, documentation and tests are included.
Credentials, local environments, dependencies, generated frontend dist, permit
PDFs, immutable analysis/evidence caches, acceptance-response dumps, obsolete
backup files and empty accidental shell-output files are excluded. Excluded
files remain on the local machine unchanged.

Rebuild the production frontend with `npm ci` and `npm run build` in `frontend`.
Use the existing README and configuration instructions for application setup.

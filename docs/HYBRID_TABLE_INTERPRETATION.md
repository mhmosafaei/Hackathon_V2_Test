# Hybrid table interpretation

The optional multimodal stage receives a rendered region only from a caller plus page, table ID, original cells, geometry, headers, neighbouring rows, and continuation context. Its structured proposals must cite existing `(row, column)` cells for every relationship and value. Validation rejects unknown cells, absent claimed values, and ambiguous geometry. Model confidence never upgrades structure quality.

No API call is made by this module. Hinkley remains a mock-only structural target until explicit authorization exists.
